# ZeichnenGrundformen

Ein Visual-Studio-Projekt zur Einführung in das Zeichnen geometrischer Grundformen innerhalb einer grafischen Benutzeroberfläche.

## Beschreibung

Das Projekt **ZeichnenGrundformen** beschäftigt sich mit den Grundlagen der grafischen Darstellung geometrischer Formen. Im Mittelpunkt stehen das Zeichnen und die Darstellung einfacher Formen sowie die Verwendung grafischer Zeichenfunktionen innerhalb einer Anwendung.

## Funktionen

- Zeichnen geometrischer Grundformen
- Darstellung von Linien, Rechtecken und Ellipsen
- Verwendung grafischer Zeichenfunktionen
- Gestaltung einfacher grafischer Elemente
- Grundlagen der zweidimensionalen Grafikprogrammierung

## Technologien

- Microsoft Visual Studio
- .NET
- Visual-Studio-Projektmappe (.sln)

## Installation und Ausführung

1. Repository klonen:

   ```bash
   git clone https://github.com/samad-pour/ZeichnenGrundformen.git
   ```

2. Die Datei `ZeichnenGrundformen.sln` in Visual Studio öffnen.
3. Das Projekt erstellen.
4. Die Anwendung mit `F5` starten.
